# BetterEasyPlace

[English](README.md) | 中文

一个改进 Litematica 轻松放置功能的 Fabric 模组。

轻松放置激活时，Litematica 会拦截所有右键操作——包括进食和使用烟花火箭（鞘翅加速）。本模组为这些操作添加了例外，并提供更多实用功能。

## 功能

- **允许进食** — 手持食物时可以在轻松放置激活时正常进食
- **允许使用烟花** — 鞘翅飞行时可以使用烟花火箭加速
- **允许潜影盒** — 轻松放置模式下可右键打开已放置的潜影盒，手持潜影盒可正常放置
- **拦截方块黑名单** — 黑名单中的方块在轻松放置模式下不会被拦截（如 `minecraft:chest`）
- **允许液体放置** *[实验性]* — 自动切换到对应桶并精确放置原理图中的液体源方块；防止空桶意外回收原理图中的液体
- **允许含水方块放置** *[实验性]* — 自动处理原理图中的含水方块（台阶、楼梯等）：先放水源再放方块使其含水，或对已放置方块用水桶含水。需同时启用「允许液体放置」
- 可通过 ModMenu 或游戏内配置界面调整（默认快捷键：`B+C`）
- 每个功能开关均可绑定独立快捷键，方便快速切换
