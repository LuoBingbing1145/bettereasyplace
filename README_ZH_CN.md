# BetterEasyPlace

[English version](README.md)

一个改进 Litematica 轻松放置功能的 Fabric 模组。

轻松放置激活时，Litematica 会拦截所有右键操作——包括进食和使用烟花火箭（鞘翅加速）。本模组为这些操作添加了例外。

## 功能

- **允许进食** — 手持食物时可以在轻松放置激活时正常进食
- **允许使用烟花** — 鞘翅飞行时可以使用烟花火箭加速
- 可通过 ModMenu 或游戏内配置界面调整（默认快捷键：`B+C`）

## 状态

本项目目前正在开发中，功能较少，可能存在问题。未来会支持更多 Minecraft 版本。

## 依赖

- Minecraft 1.20.1
- Fabric Loader
- [Litematica](https://www.curseforge.com/minecraft/mc-mods/litematica)
- [MaLiLib](https://www.curseforge.com/minecraft/mc-mods/malilib)
- [ModMenu](https://modrinth.com/mod/modmenu)（可选，用于配置界面）
